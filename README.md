# 📱 QUANTUM_MOBILE

> **Smartphones, Accessories & Device Repair Reservation Platform**  
> Full-Stack MERN Application (MongoDB, Express, React, Node.js)  
> **Author:** Teshan G.H.P  

---

## 🌟 Overview
Quantum Mobile is a modern web platform combining high-end consumer technology retail with an end-to-end device repair reservation system. Customers can explore flagship devices, book walk-in appointments or courier pickups, track repair progress in real time, and consult with store specialists.

---

## 🚀 Key Features

* **Flagship Devices Catalog:** Apple iPhone 16 Pro, Samsung Galaxy S24 Ultra, and Google Pixel 9 Pro with dynamic storage/color variants.
* **Accessories Hub:** Fast GaN chargers, military-grade MagSafe cases, tempered screen protectors, and audio accessories.
* **Storefront Experience:** Hero carousel, brand marquee ticker, and clean white modern UI.
* **Live Specialist Consultation:** Real-time specialist desk for stock availability and warranty checks.
* **Modern Tech Stack:** React (Vite), React Router v6, Lucide Icons, and Vanilla CSS design system.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5174](http://localhost:5174) in your browser.
